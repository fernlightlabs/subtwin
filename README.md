# Subtwin — Dual Subtitles for YouTube

Subtwin is a Chrome extension that shows the original subtitles and a translation together on YouTube.

- Readable, sentence-by-sentence lines, also for auto-generated captions
- Uses a video's own human translation when it exists; otherwise YouTube translation or Chrome's on-device AI translation
- Private: no account, no analytics, nothing uploaded
- Learner shortcuts: Alt+A / Alt+D previous / next sentence, Alt+R replay, Alt+P pause after each sentence, Alt+S on/off for this video
